# blackjack
A blackjack app I made to celebrate the fact that I managed to code a deck of cards in Javascript :yippee:

# IMPORTANT
This code is *unsigned.* Most operating systems get mad at you for running unsigned code, since there is no way to know if it is malicious or not. While I can promise you that all this app does is let you play Blackjack, you still shouldn't run random code from the internet.

Also there aren't any MacOS builds because I don't feel like testing in a MacOS VM.
